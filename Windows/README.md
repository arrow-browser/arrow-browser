# Arrow for Windows

The Windows app: WinUI 3, through Swift projections of the WinRT APIs
generated by [swift-winrt](https://github.com/thebrowsercompany/swift-winrt),
on ArrowCore and ArrowCEF ([portability](../docs/PORTABILITY.md), phase 5).

Its interface is Arc's on Windows, in look and in function:

- The toolbar in the title bar: the app menu under the logo (Arc's, with its
  Spaces, Tabs, Extensions, Developer and Help menus), the sidebar toggle,
  navigation, the address with Copy Link and the Site Control Center (its
  Share URL opens Windows' share sheet), Translate (in the page, into
  Windows' display language) and Split View Options.
- The sidebar: the favorites, the space's pinned tabs and folders (the
  GitHub Live Folder among them: the open pull requests of the user signed
  in to GitHub, read from github.com as Arc does), the "Clear" divider, New
  Tab, today's tabs; Arc's context menus (tab, favorite, folder, space),
  renaming in place, dragging to reorder, pin or file away; the media
  controls of a tab playing out of sight; the archive, the space switcher
  and the Add menu at the bottom.
- The command bar (Ctrl+T, Ctrl+L) as Arc's on Windows: five rows, a
  well-known site completed in the field, the search, Arc's commands with
  their shortcuts, open tabs and suggestions.
- Find in page (Ctrl+F), history, downloads, split views of up to four
  panes, Peek for links leaving pinned tabs, Little Arrow for links from
  other apps, new and incognito windows, and the settings window (with the
  Arrow Card). Set Arrow as Default Browser registers Arrow with Windows and
  opens its Default apps page.
- The space's theme over the Mica backdrop, titles in a dark shade of its
  hue; dialogs for creating spaces, their icon and theme color.

Tabs and the selection are saved like on macOS; saved logins, payment cards
and Arrow Cloud's secrets go to the Credential Manager.

## Requirements

- Windows 10 1809 or later, x64 or arm64.
- Swift 6.4.1 for Windows, with the Windows SDK it installs.
- The [Windows App SDK](https://learn.microsoft.com/windows/apps/windows-app-sdk/)
  2.5 runtime. `generate-winrt.ps1` downloads its MSIX packages; install them
  once (framework first):

  ```powershell
  $arch = if ($env:PROCESSOR_ARCHITECTURE -eq 'ARM64') { 'arm64' } else { 'x64' }
  Get-ChildItem "Windows\.packages\Microsoft.WindowsAppSDK.Runtime.*\tools\MSIX\win10-$arch\*.msix" |
      Sort-Object { $_.Name -ne 'Microsoft.WindowsAppRuntime.2.msix' } | ForEach-Object { Add-AppxPackage $_.FullName }
  ```

## Build and run

From the repository root, in PowerShell (`scripts/fetch-cef.sh` runs in Git
Bash):

```powershell
bash scripts/fetch-cef.sh                     # CEF for this machine, in Vendor\cef
powershell -File Windows\generate-winrt.ps1   # the WinRT projections
cd Windows
swift build --product Arrow
$bin = swift build --show-bin-path
powershell -File stage.ps1 $bin               # Arrow.exe and its runtime, next to Arrow.dll
& "$bin\Arrow.exe" https://example.com
```

- `generate-winrt.ps1` projects the types listed in `projections.json`, and
  those their members use, into `Sources/CWinRT` and
  `Sources/<module>/Generated`, which are not versioned. Add a type there
  before using it. The NuGet packages it fetches (swift-winrt, the Windows App
  SDK) go in `.packages`.
- `Arrow.exe` is CEF's bootstrap executable renamed: it loads `Arrow.dll` and
  hands it the sandbox of Chromium's subprocesses. `stage.ps1 -Console`
  installs the console variant, which keeps the app's output:
  `Arrow.exe --smoke` loads the page, prints its title and quits (CI).
- `swift test` runs once the app is staged (its tests load `libcef.dll`), in
  a desktop session: the Credential Manager refuses writes in sessions
  without credentials, such as SSH with a key.
- Profiles live in `%LOCALAPPDATA%\Arrow`, Arrow's own data (sidebar,
  settings, history) in its `State` folder. `--smoke` uses a new profile in
  `%TEMP%\arrow-smoke`.

## Layout

| Path | Contents |
|---|---|
| `Sources/ArrowWindows` | The app: entry points, the browser window (its actions, spaces, tools and Peek in extensions), its sidebar, command bar, find bar, menus and sheets, the settings and Little Arrow windows, the commands and their keyboard shortcuts (`CommandCatalog`), the space theme's brushes, platform services (`WindowsPlatform`, the Credential Manager, `ShareSheet`, `DefaultBrowser`), `LiveFolders`, CEF's message pump |
| `Tests/ArrowWindowsTests` | Tests of the Windows-specific code |
| `Sources/WinUI/Application` | `XamlApplication`, a WinUI application written in Swift (adapted from swift-winui) |
| `Sources/CWinRT`, `Sources/*/Generated` | Generated projections |
